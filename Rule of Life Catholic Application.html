How to Get Your Own Free HTTPS Web Address

You can deploy this application for 100% FREE in 2 minutes so that you have your own private HTTPS URL accessible on all your devices:

Option A: GitHub Pages (Easiest)
  1. Create a free account at GitHub.com.
  2. Create a new repository named rule-of-life.
  3. Upload this index.html file to the repo.
  4. Go to Settings > Pages, select main branch, and click Save.
  5. Your app is now published at: https://yourusername.github.io/rule-of-life
Option B: Netlify / Vercel Drag-and-Drop
  1. Go to Netlify Drop or Vercel.
  2. Drag and drop the folder containing this index.html file.
  3. Get an instant, secure personal URL like https://my-rule-of-life.netlify.app.

Add to Phone Home Screen (iPhone / Android)

  • iPhone (Safari): Open your web link, tap the Share button, then select "Add to Home Screen".
  • Android (Chrome): Open your web link, tap the 3 dots menu, and tap "Install app" or "Add to Home screen".
